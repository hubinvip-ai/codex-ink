# Codex Ink 0.3.0 — Bilingual Source Preview

App version **0.3.0**, build **4**. Source developer preview under [GPL-3.0-only](../../LICENSE).

## English

- Choose **Simplified Chinese or English** in **Overview → 语言 / Language**. Settings, menu bar, app-owned status/error messages, previews and e-ink frames follow the saved language.
- Existing settings remain in Chinese. Changing language preserves display binding, sync enablement and pause state; the old rendering session is stopped before regenerating the preview.
- Native English labels, dates and task status badges fit the existing **400×300 black/white/red** layout. Project, task and device names retain their original text.
- The HTML editor supports language selection, persistence and `?language=en&screen`; exports retain the selected language and chart.
- Existing Chinese public baseline and bundled-font portability are preserved.

### Validation and limitations

The public source passes 243 Python cases, including the driver for 55 native Swift checks, plus two core Swift suites, release build and development packaging/signature verification. Hosted results: [GitHub Actions](https://github.com/hubinvip-ai/codex-ink/actions).

This release provides **source archives only**, following v0.2.1. It requires an external Python/Pillow runtime. No standalone installer or notarized DMG is attached. English physical-display appearance, complete settings-window inspection, second-Mac setup, sleep/wake and long-running reliability remain separate acceptance items.

Build using the [installation guide](../installation.md). Keep a backup of your settings before upgrading. The new app reads existing v1 settings; once `language` is saved, older builds that strictly reject unknown fields cannot read that file without restoring the backup.

## 简体中文

- 概览新增 **语言 / Language**，支持简体中文与 English；设置、菜单栏、应用自有状态与错误、预览及墨水屏同步切换。
- 旧配置默认中文。切换保留设备绑定、同步开关及暂停状态；先结束旧渲染会话，再生成新语言预览。
- 英文标题、日期、状态标签沿用 **400×300 黑白红三色**布局；项目、任务和设备名保留原文。
- HTML 编辑器支持语言保存、英文屏幕预览与保留语言及图表的导出。中文公开基线与跨 Mac 字体兼容保持不变。

公开目录通过 243 个 Python 用例（其中原生驱动包含 55 项 Swift 检查）、2 组核心 Swift 测试、Release 构建及开发打包签名验证。在线结果见 [GitHub Actions](https://github.com/hubinvip-ai/codex-ink/actions)。

本版沿用源码预览发布方式，不附独立应用或已公证 DMG，仍依赖外部 Python/Pillow。英文实屏、完整设置窗口及第二台 Mac、休眠与长期稳定性仍需单独确认。

按[中文安装指南](../installation.zh-CN.md)构建。升级前保留设置备份；新版兼容旧 v1 配置，保存新增的 `language` 后，旧版严格字段检查会拒绝该文件，回退需恢复备份。
