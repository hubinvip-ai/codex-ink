# Codex Ink 0.2.1 — Developer Preview

**Source developer preview.** Tag: `v0.2.1`; app metadata: `0.2.1` (build `3`). Project code: [GPL-3.0-only](../../LICENSE). Source archives are provided by GitHub; no standalone app installer is attached.

## English

Codex Ink brings Codex quota and task status to a compatible 400 × 300 Bluetooth e-paper display beside your Mac.

### Included

- Native macOS menu bar app with real-data preview, device binding, pause/resume and login startup.
- Weekly quota, next reset, 30-day usage trend and up to three task rows.
- Local Codex hooks and app-server data access; a private process pipe connects the worker and native Bluetooth sender.
- Persistent refresh requests, duplicate-frame suppression and bounded recovery after transient failures.
- Saved configuration selection for ordinary and login launches, including custom state directories.
- The approved black/white/red device layout; current UI language is Simplified Chinese.

### Checked locally

The private development checkout passed 239 Python tests, including a driver for 52 native Swift checks. Configuration recovery, controlled hook migration and automatic refresh were confirmed separately on the maintainer’s existing installation. The public snapshot was rebuilt in a fresh virtual environment: all 239 Python cases passed, including 52 nested native Swift checks; 2 core Swift suites, release build, app packaging and strict ad-hoc signature verification passed. Hosted build results are available in [GitHub Actions](https://github.com/hubinvip-ai/codex-ink/actions).

### Before trying it

Build from source using the [installation guide](../installation.md). External Python/Pillow and a signed-in compatible Codex installation are required. Only one Apple Silicon Mac and one display matching the documented protocol have been verified.

No notarized DMG, independent runtime bundle or automatic upgrade migration is provided. Intel, other displays, second-Mac installation, real logout/login, three sleep/wake cycles and 24-hour reliability remain unverified. Packet completion is not a physical display appearance check.

Read the [privacy notes](../PRIVACY.md) before sharing diagnostics. Report your versions, hardware, failing step and redacted error.

## 简体中文

Codex Ink 将 Codex 使用额度和任务状态同步到 Mac 旁的 400 × 300 蓝牙墨水屏。

### 本版内容

- 原生菜单栏应用：真实预览、设备绑定、暂停/继续与登录启动。
- 每周额度、下次重置、30 天用量趋势及最多三条任务。
- 本地 hooks 与 app-server 数据读取，Python worker 和原生蓝牙发送通过私有管道通信。
- 刷新请求持久化、重复画面跳过和暂时故障恢复。
- 普通启动与登录启动记住所选配置目录，支持既有自定义目录。
- 保持已确认的黑白红设备布局，当前界面为简体中文。

### 本机验证

开发目录通过 239 个 Python 测试用例，其中原生驱动包含 52 项 Swift 检查。维护者既有安装另行验证了配置恢复、受控 hooks 迁移和自动刷新。公开源码在新建虚拟环境中重新验证：239 个 Python 用例全部通过（包含 52 项原生 Swift 检查），2 组 Swift 核心测试、release 构建、应用打包和严格签名校验通过。在线构建结果见 [GitHub Actions](https://github.com/hubinvip-ai/codex-ink/actions)。

### 使用边界

按[安装指南](../installation.zh-CN.md)从源码构建，需要外部 Python/Pillow 和已登录且接口兼容的 Codex。只验证过一台 Apple Silicon Mac 与一台符合记录协议的屏幕。

尚无已公证 DMG、独立运行环境或自动升级迁移。Intel、其他屏幕、第二台 Mac、真实注销/登录、三次休眠唤醒和 24 小时稳定性均待验收；包写入完成不代表实屏外观确认。

## Changes in this snapshot

- Recover the worker after transient setup inspection failures while preserving an explicit pause.
- Treat a freshly confirmed same-user zombie as exited; unreadable live processes still block setup.
- Retry transient send-preflight errors while keeping configuration/trust failures actionable.
- Handle fragmented app-server output and close owned processes/pipes on initialization failure.
- Keep the snapshot clock current without changing individual task timestamps.
- Use consistent primary actions in the menu and settings overview.
- Include the approved AppIcon and template menu-bar icons.
- Use fictional publication fixtures, bilingual documentation and origin story, provenance notes, and a pinned macOS CI workflow.
- Make executable test fixtures work when the selected Python path contains spaces.
