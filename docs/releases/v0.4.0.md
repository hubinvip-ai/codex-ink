# Codex Ink 0.4.0 — Calmer Sync & Simpler Menu

## English

This source preview reduces automatic e-ink refreshes and simplifies the macOS menu.

- Automatic refresh: 30-second coalescing, at least 180 seconds after the last successful send, and periodic data polling every 600 seconds. Manual refresh remains available.
- Ordinary resume does not force a refresh. Content deduplication ignores read/event timestamps within the current worker session.
- Icon-only menu bar with a blue syncing dot or red attention dot; shorter error summaries and a single pause/resume action.
- Generated local updater preserves trusted hooks, replaces the independent sync runtime, waits for in-flight delivery, and keeps a rollback copy.
- Startup health allows bounded recovery for up to 90 seconds, while still requiring fresh readiness. Persistent failures roll back.

Local validation: 280 Python cases across 11 suites (including a driver with 63 native Swift checks), two core Swift suites, Release build, and development packaging/signature verification.

Source archives only. External Python/Pillow is required; no standalone installer or notarized DMG is attached. The device layout and public fictional baselines are unchanged. Occasional underlying system-level inspection delays and long-term, cross-machine behavior remain validation limits.

## 简体中文

本次源码预览版降低自动刷新频率，简化 Mac 菜单。

- 自动刷新采用 30 秒合并、距上次成功至少 180 秒、每 600 秒定时取数；保留手动立即刷新。
- 普通继续同步不强制刷屏，当前 worker 内的内容去重忽略读取和事件时间。
- 状态栏仅保留图标，同步中蓝点、需要处理红点；缩短错误提示，去除重复的继续同步入口。
- 构建生成本地更新程序，保留已信任 Hooks，独立更新同步代码，等待当前发送完成，并保留回退副本。
- 更新后启动恢复窗口最多 90 秒，仍须重新确认就绪；持续失败则回退。

沿用源码发布方式，仍需外部 Python/Pillow，不附独立安装包或公证 DMG。设备布局与公开虚构基线不变。偶发系统层检查延迟的底层原因、跨机器及长期稳定性仍需继续验证。
