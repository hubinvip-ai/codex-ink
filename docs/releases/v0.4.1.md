# Codex Ink 0.4.1 — Daily Bars & Calendar Weeks

## English

Fixes the 30-day chart inserting artificial empty slots between days. It now renders exactly one bar per calendar day, with extra spacing only between Sunday and Monday. Weeks run Monday through Sunday, continue across month boundaries, and may be partial at the edges of the 30-day window.

Real zero-usage days retain their position. The metric remains daily tokens; this does not claim equivalence with the web dashboard's plan-usage metric. Height scaling, the rest of the 400×300 layout and the 30/180/600-second refresh policy are unchanged. HTML and native rendering follow the same calendar-week rule. New fictional public-v1.4 samples preserve older baselines.

Local validation: 282 Python test cases across 11 suites (including a driver with 63 Swift checks), 2 core Swift suites, Release build and development package/signature checks passed.

Source developer preview, GPL-3.0-only. External Python/Pillow is still required. No standalone installer or notarized DMG is attached; physical-display appearance and cross-machine reliability remain separate acceptance items.

真实零用量保留日期位置。统计仍为每日 tokens，不宣称与后台套餐用量等价。柱高规则、图表之外的 400×300 排版及 30/180/600 秒刷新策略不变。HTML 与原生保持相同规则，新增 public-v1.4 虚构样例，旧基线不覆盖。

本版为 GPL-3.0-only 源码开发预览，仍需外部 Python/Pillow，不附独立安装包或公证 DMG；实屏观感和跨机器稳定性分别验收。
