# Codex Ink 0.4.2 — Weekly Usage Peaks

## English

Red bars now identify the highest positive daily usage in each Monday–Sunday calendar week, replacing the fixed decorative red bar. All tied maxima are highlighted. All-zero weeks stay black. Partial weeks at the edges compare only dates visible in the 30-day window. Comparisons use raw daily values, not rounded pixel heights.

HTML, native rendering and fictional public-v1.5 samples are aligned. Bar geometry, daily Token metric, other dashboard regions and refresh policy are unchanged. Tests cover ties, zero weeks, partial weeks and a year boundary.

Local validation: 283 Python cases across 11 suites (including 63 native Swift checks in one driver), two core Swift suites, Release build and development packaging/signature verification passed.

Source developer preview, GPL-3.0-only. External Python/Pillow is required. No standalone installer or notarized DMG is attached; physical-display and cross-machine validation remain separate.

## 简体中文

红柱改为表示每个自然周（周一至周日）内的每日用量最高值，移除固定装饰性红柱。最高正值并列时全部标红，全零周不标红；首尾不完整周只比较当前 30 天窗口内的日期。按原始数值比较，不以取整后的像素高度判断。

HTML、原生渲染及 public-v1.5 虚构样例同步，柱体几何、每日 Token 口径、其他区域和刷新策略不变。测试覆盖并列、全零、首尾不完整周和跨年边界。

沿用 GPL-3.0-only 源码预览方式，仍需外部 Python/Pillow，不附独立安装包或公证 DMG。
