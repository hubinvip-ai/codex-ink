# Public UI fixture · v1.2

This sample preserves the approved 400×300 layout and uses fictional account, task and quota data. It was generated with `docs/release-assets/render_demo.py` and Pillow 11.3.0. It is a native renderer fixture, not a photograph or browser screenshot.

The original private development baseline and its history are not distributed. Keep this public fixture unchanged when changing data-source or BLE behavior. For an intentional visual change, update the UI specification and create a new baseline version.
